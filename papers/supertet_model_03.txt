117 मेमोरी
? EPROM का पूरा नाम क्या है?
! What is the full form of EPROM?
- Erasable Programmable Read Only Memory
- Electrically Programmable ROM
- External Programmable ROM
- Extended Programmable ROM
= EPROM — पराबैंगनी किरणों से मिटाई जा सकने वाली ROM।
118 ऑपरेटिंग सिस्टम
? पहला GUI आधारित Operating System किस कंपनी ने विकसित किया था?
! Which company developed the first GUI-based Operating System?
- Microsoft
- Apple
- IBM
- Intel
= उत्तर कुंजी के अनुसार Apple (Lisa/Macintosh)। (GUI की शुरुआत Xerox PARC में हुई थी।)
119 लॉजिक गेट
? किस Logic Gate को Universal Gate कहा जाता है?
! Which Logic Gate is called a Universal Gate?
- AND
- OR
- NAND
- XOR
= NAND (और NOR) से कोई भी गेट बनाया जा सकता है।
120 मेमोरी
? किस मेमोरी का Access Time सबसे कम होता है?
! Which memory has the shortest access time?
- Cache Memory
- RAM
- ROM
- Hard Disk
= Register > Cache > RAM > Hard Disk (गति के क्रम में)।
